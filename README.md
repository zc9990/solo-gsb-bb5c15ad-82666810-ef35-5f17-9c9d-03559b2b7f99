# 盲文标签排版台（Braille Label Studio）

输入英文标签文字与板材宽/高、点距、行距，系统按**六点一级盲文**转换并排版；另提供**压印质检**模式，将实测凸点 CSV 与最近一次成功排版的设计点逐一比对：

- 大写字母前自动添加大写前缀 `⠠`（点 6）
- 连续数字段只在段首添加一个数字前缀 `⠼`（点 3-4-5-6）
- 依据转换后的盲文单元**整词换行**，词间空一个空白单元
- 任何单词放不下、或总行数超出板材容量时，**明确指出原因，绝不裁切**
- 页面实时预览带毫米（mm）坐标的凸点 SVG，并可下载 **SVG** 与**排版 JSON**
- **压印质检**：粘贴实测凸点 CSV、设置校准旋转角/偏移/合格公差/关联半径，叠加 SVG 区分四类结果并下载质检报告 CSV
- **自动校准**：实测点顺序无须对应，设置 X/Y 最大校准量后一键估算全局平移并写回偏移、自动重跑；另可设置**最大旋转角与角度步长**启用**小角度刚体校准**（围绕板材中心的旋转 × 平移联合搜索）；正确处理缺失点与多余点，不使用质心差

## 一条命令启动（Docker Compose）

```bash
docker compose up --build
```

Compose 会在构建镜像时自动完成依赖安装与初始化。启动后在浏览器访问：

**http://localhost:3000** （容器内外端口均为 `3000`）

页面顶部两个页签即为入口：

- **排版模式**（`http://localhost:3000/`，默认页签）：盲文转换、整词换行排版与 SVG/JSON 下载；
- **压印质检**：同一页面点击顶部「**压印质检**」页签进入，以当前会话中最近一次成功排版的设计点为基准。

停止：`docker compose down`

## 本地开发（不用 Docker）

```bash
npm install
npm start          # 同样监听 http://localhost:3000
npm test           # 运行转换/排版/质检单元测试（node:test）
```

## 使用说明（排版模式）

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| 标签文字 | 英文标签（A–Z、a–z、0–9 及常用标点，≤500 字符） | `EXIT Door 2` |
| 板材宽度 / 高度 | 标签板材幅面，单位 mm | 100 × 50 |
| 点距 | 单元内相邻凸点中心距，单位 mm | 2.5（标准盲文） |
| 行距 | 相邻两行顶行点的中心距，单位 mm | 10（标准盲文） |
| 边距（高级） | 板材四周边距，单位 mm | 5 |
| 字距（高级） | 相邻单元净间距，留空 = 1.4×点距（标准 → 6mm 单元pitch） | 自动 |
| 凸点直径（高级） | 留空 = 0.6×点距（标准 ≈1.5mm） | 自动 |

放不下时的报错示例：

- `单词 “EXIT” 转换后占 6 个盲文单元（含大写/数字前缀），超过每行最多 4 个单元……`
- `整词换行后共需 5 行，板材有效高度仅容纳 4 行……`

## 压印质检模式

进入「压印质检」页签前请先在「排版模式」完成一次成功排版（左侧绿色基准条会显示基准标签文字、设计点数与排版时间；排版失败不会覆盖基准）。

| 输入 | 含义 |
| --- | --- |
| 实测凸点 CSV | 每行一个点，两列 `x_mm,y_mm`（mm）；首行可为 `x_mm,y_mm` 表头（可省略），允许空行；**点的顺序无须与设计点对应** |
| X / Y 校准偏移 | 对旋转后的实测坐标再整体平移：比较坐标 = R(旋转角)·(实测−板材中心) + 板材中心 + (offsetX, offsetY) |
| 校准旋转角 | 实测点围绕板材中心（板材幅面之半）的刚体旋转角（度，逆时针为正），默认 0；由「一键自动校准」自动写回 |
| 合格公差 | 配对欧氏距离 ≤ 公差判为「合格」，否则为「偏移超差」 |
| 最大关联半径 | 只有设计点与刚体校准后实测点距离 ≤ 半径时才允许配对 |
| X / Y 最大校准量 | 「一键自动校准」的候选限幅：仅保留 \|dx\|、\|dy\| 均不超限的候选平移（默认 2 mm） |
| 最大旋转角 / 角度步长 | 小角度刚体搜索范围与采样步长（度）：角度在 `[-最大旋转角, 最大旋转角]` 内按步长枚举（含 0°）。最大旋转角留 `0` 时只估平移（与旧版一致）；最大旋转角上限 15° |

比较算法：在关联半径构成的二分图上做**一对一最优匹配**，优先级依次为 ① 匹配对数最多 → ② 总欧氏距离最小 → ③ 再相同则按设计点序号与 CSV 行号稳定决胜（每个实测点最多匹配一个设计点，绝不重复配对）。未配对的设计点记为**缺失**，未配对的实测点记为**多余**。

### 一键自动校准（全局平移 / 小角度刚体）

粘贴无序实测点、设好 **X/Y 最大校准量**后点击「**一键自动校准（平移 / 小角度刚体）**」。

**模式一：仅估算全局平移**（最大旋转角留 `0`，或直接不传角度参数，与旧版完全兼容）：

1. 以每个「设计点 i − 实测点 j」的差值 `(dx,dy)=(x设计−x实测, y设计−y实测)` 作为候选全局平移（令比较坐标 实测+(dx,dy) 尽量贴合设计）；
2. **仅保留两轴均未超限者**：`|dx| ≤ 最大X校准量` 且 `|dy| ≤ 最大Y校准量`，候选按 1e-6 mm 量化去重；
3. 每个候选都复用质检的同一套**一对一匹配**（受同一最大关联半径约束），依次按
   **① 匹配对数最多 → ② 配对总残差（欧氏距离之和）最小 → ③ |dx|+|dy| 最小 → ④ dx 升序、再 dy 升序**
   确定唯一平移。

**模式二：小角度刚体校准**（最大旋转角填正数，如 `3`，并设置角度步长，如 `0.1`）：

1. 角度在 `[-最大旋转角, 最大旋转角]` 内按步长枚举（**始终包含 0° 与两侧端点**，按 1e-6 度去重），最大旋转角不得超过 15°、枚举角度数不超过 201 个；
2. 每个候选角度先把**实测点围绕板材中心**（`plateWidth/2, plateHeight/2`；未提供板材幅面时取设计点包围盒中心）做刚体旋转，再在现有 **X/Y 限幅内枚举候选平移**，即「角度 × 平移」联合搜索，候选评估总数有上限保护（20 万个）；
3. 每个（角度, 平移）候选都复用质检的同一套**一对一匹配**，依次按
   **① 匹配对数最多 → ② 配对总残差最小 → ③ 旋转角绝对值最小（能不转就不转）→ ④ |dx|+|dy| 最小 → ⑤ dx 升序、dy 升序、角度升序**
   确定唯一刚体参数；
4. 估算的**旋转角写回「校准旋转角」、平移写回 X/Y 偏移输入框并立即重跑**合格/偏移超差/缺失/多余四类判定，绿色提示条同步显示角度个数、角度×平移候选数、匹配对数、总残差与旋转中心。

注意：两种模式下缺失的设计点和多余的实测点都不参与任何候选的配对统计，因此**不会被离群点拉偏——本功能不使用质心差替代**。若搜索范围内没有任何有效候选（或参数/CSV 非法、计算量超上限），**角度与偏移输入框全部保留原值不变**，并在黄色提示条中给出明确原因（是角度范围不足、平移限幅过小还是 CSV/半径问题），不会清空或写入错误参数。

- CSV 解析错误会逐条定位到**具体物理行号（和列号）**，例如 `第 3 行：列数为 1，应为 2 列（x_mm,y_mm）`
- 叠加 SVG 用四类颜色区分：🟩 合格（绿）/ 🟧 偏移超差（橙）/ 🟥 缺失（红）/ 🟣 多余（紫）；○ 为设计点、◆ 为经刚体校准（旋转+平移）后的实测点，细线连接配对；元素上带 `data-rotation`、`data-center-x/y`、`data-measured-x/y` 属性，图内 `<desc>` 注明所用角度与中心
- 指标：**通过率**（合格对数 / 设计点总数）、**最大偏差**、**平均偏差**（均只统计配对点），以及配对/缺失/多余计数
- **下载质检报告 CSV**：含设计点序号与设计坐标、CSV 行号与**原始实测坐标**、**校正（旋转+平移后）坐标**、配对距离、中文结论（合格/偏移超差/缺失/多余）与**该行所用旋转角 `rotation_deg`**，并附汇总行及参数行（含旋转角与旋转中心，UTF-8 BOM，Excel 可直接打开）；另可下载叠加 SVG

## API

### `POST /api/layout`

```json
{ "text": "EXIT Door 2", "plateWidth": 100, "plateHeight": 50, "dotSpacing": 2.5, "lineSpacing": 10, "margin": 5 }
```

返回 `{ ok, errors, params, cellsPerLine, maxLines, lines, dots, brailleText, stats, svg }`：

- `ok=false` 时 `errors` 列出放不下的具体原因，`svg/dots` 为空（不输出裁切结果）
- `dots[].x/y/r` 为每个凸点的毫米坐标，`svg` 为完整 SVG 文档（`width/height` 以 mm 标注）

### `POST /api/qc`

```json
{
  "design": [{ "x": 5, "y": 5, "r": 0.75 }],
  "csv": "x_mm,y_mm\n5.2,4.9",
  "offsetX": 0, "offsetY": 0, "rotation": 0,
  "tolerance": 0.5, "maxRadius": 2,
  "plateWidth": 100, "plateHeight": 50
}
```

返回 `{ ok, errors, params, baseline, transform, measuredCount, pairs, missing, extra, stats, svg, csv }`：

- `ok=false` 时 `errors[]` 含参数错误与逐行（`line` 列）CSV 解析错误，`svg/csv` 为空
- `params.rotation` 为本次质检使用的旋转角（度，缺省请求字段时为 `0`）；`transform.centerX/centerY` 为旋转中心（板材中心，缺幅面时为设计点包围盒中心）
- `pairs[]` 含双方坐标、**原始实测坐标** `measuredX/Y`、**校正坐标** `correctedX/Y`、距离与 `verdict`（`pass` / `offset`）；`missing[]`、`extra[]` 为未配项
- `stats` 含 `passRatePercent`、`maxDeviation`、`meanDeviation` 等；`csv` 为可直接下载的报告文本（明细末列 `rotation_deg`，参数行含旋转角与旋转中心）

### `POST /api/qc/calibrate`

纯平移（旧调用，不传任何角度字段，完全向后兼容）：

```json
{
  "design": [{ "x": 5, "y": 5, "r": 0.75 }],
  "csv": "5.4,5.25",
  "maxOffsetX": 2, "maxOffsetY": 2,
  "maxRadius": 2
}
```

小角度刚体校准（新增 `maxAngle` / `angleStep`，均为度；另建议传板材幅面以确定旋转中心）：

```json
{
  "design": [{ "x": 20, "y": 15 }],
  "csv": "20.1,14.8",
  "maxOffsetX": 2, "maxOffsetY": 2,
  "maxRadius": 2,
  "maxAngle": 3, "angleStep": 0.1,
  "plateWidth": 100, "plateHeight": 50
}
```

自动校准：纯平移模式枚举「设计点－实测点」候选平移并限幅去重；刚体模式在 `±maxAngle` 内按步长枚举角度（含 0°），实测点围绕板材中心旋转后再枚举限幅内平移。每个候选复用一对一匹配，按匹配数 → 总残差 →（刚体模式）旋转绝对值 → |dx|+|dy| → dx/dy/角度升序决出唯一结果。

返回 `{ ok, errors, offsetX, offsetY, rotation, centerX, centerY, matchedCount, totalResidual, designCount, measuredCount, candidateCount, rigidMode, angleCount }`：

- `ok=true` 时 `offsetX/offsetY` 为建议写回偏移框的平移（mm，4 位小数），`rotation` 为旋转角（纯平移模式恒为 `0`），`centerX/centerY` 为旋转中心；`matchedCount` 为该参数下的匹配对数，`totalResidual` 为配对总残差，`candidateCount` 为限幅去重后的候选数（刚体模式为各角度候选总数），`rigidMode` 标识是否启用了角度搜索，`angleCount` 为枚举角度数（纯平移模式为 `null`）；
- `ok=false`（无可用候选、参数/CSV 错误、点数或计算量超上限）时 `offsetX/offsetY/rotation` 均为 `null`，`errors[]` 给出明确原因，调用方应保留角度与偏移输入框原值。只传 `maxAngle` 与 `angleStep` 其中之一会被视为参数错误（不会静默退化为纯平移）。

健康检查：`GET /api/health`

## 项目结构

```
├── server.js            # Express 服务：静态页面 + /api/layout + /api/qc + /api/qc/calibrate
├── lib/braille.js       # 核心：一级盲文转换、整词换行排版、毫米坐标 SVG 生成
├── lib/qc.js            # 核心：实测 CSV 解析（行号定位）、一对一最优匹配、判定/SVG/CSV 报告、自动校准（纯平移 + 小角度刚体）
├── public/              # 原生前端（index.html / app.js / style.css）
├── test/                # node:test 单元测试（排版 + 质检）
├── Dockerfile           # 单阶段构建，npm install + 启动
└── docker-compose.yml   # 一条命令编排启动
```
